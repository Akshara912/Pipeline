AWS Project - CI/CD PipelineThis project features a multi-stage GitLab CI/CD pipeline that automates container building, execution of a Python script using a custom container environment, and deployment of the resulting output to an AWS S3 bucket.🚀 Pipeline ArchitectureThe pipeline consists of three sequential stages:Code snippetgraph TD
    A[.pre: docker_stage] -->|Builds & Pushes Docker Image| B[build: python_stage]
    B -->|Generates output.txt via add.py| C[deploy: aws_stage]
    C -->|Uploads output to S3| D((AWS S3 Bucket))
📋 Pipeline Stages Breakdown1. docker_stage (.pre)Purpose: Builds a custom Docker image and pushes it to the GitLab Container Registry.Environment: Uses Docker-in-Docker (docker:dind).Actions:Logs into the GitLab Container Registry using CI variables ($CI_REGISTRY_USER, $CI_REGISTRY_PASSWORD).Builds the Docker image from the local dockerfile.Pushes the image to $CI_REGISTRY_IMAGE/dockerfile.2. python_stage (build)Purpose: Runs a Python script inside the newly built and published custom container environment.Environment: Uses [registry.gitlab.com/akshara912/aws_project/dockerfile](https://registry.gitlab.com/akshara912/aws_project/dockerfile).Actions:Creates a local python/ directory.Executes add.py and pipes the output into python/output.txt.Artifacts: Saves python/output.txt so it can be passed along to subsequent deployment stages.3. aws_stage (deploy)Purpose: Deploys the generated output file to an Amazon S3 bucket.Environment: Uses the official amazon/aws-cli image.Actions:Verifies the AWS CLI version.Copies python/output.txt to the target S3 bucket specified by $AWS_S3_BUCKET.⚙️ Required CI/CD VariablesTo make this pipeline run successfully, configure the following variables under your GitLab project settings (Settings > CI/CD > Variables):Variable NameDescriptionTypeAWS_ACCESS_KEY_IDYour AWS IAM access key with permissions to write to the S3 bucket.VariableAWS_SECRET_ACCESS_KEYYour AWS IAM secret access key.Variable (Masked)AWS_DEFAULT_REGIONThe AWS region where your S3 bucket resides (e.g., us-east-1).VariableAWS_S3_BUCKETThe name of your target S3 bucket (e.g., my-project-output-bucket).Variable(Note: GitLab automatically provides $CI_REGISTRY, $CI_REGISTRY_USER, $CI_REGISTRY_PASSWORD, and $CI_REGISTRY_IMAGE for the container registry stage.)🛠️ Project StructurePlaintext├── .gitlab-ci.yml    # CI/CD pipeline configuration
